# Images

The project ships with **illustrations** (SVG) generated by `tools/generate_images.py`, so every page has artwork out of the box.
They are stylised drawings, not photographs.

## Use real photos instead (optional)
1. Save your photo in the same folder with the same name but a `.jpg` extension (for example `public/images/moods/romantic.jpg`).
2. In `src/data/moods.json`, `places.json` and `movies.json`, change that file's path from `.svg` to `.jpg`.
3. Credit the photographer in the README (Wikimedia Commons and Unsplash are good free sources).

## Regenerate the illustrations
```bash
python3 tools/generate_images.py
```

## Where the files are
- `public/images/moods/<mood>.svg` (4 files)
- `public/images/places/<place-id>-1.svg` and `-2.svg` (28 files)
- `public/images/posters/<movie-id>.svg` (4 title cards, typographic illustrations, not the real film posters)
